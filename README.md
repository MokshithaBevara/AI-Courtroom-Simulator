# 🏛️ AI Courtroom Simulator

A multi-agent AI system that simulates a courtroom debate where different agents argue a statement and a judge delivers a final verdict using reasoning and real-time web evidence.

---

## 🚀 Overview

This project simulates a legal-style AI debate system using multiple agents:

* 🌐 Live Evidence Retriever (DDGS Search)
* 🟢 Prosecution Agent (Supports claim)
* 🔴 Defense Agent (Opposes claim)
* ⚖️ Judge Agent (Final decision maker)

---

## 🧠 Architecture

User Input → Web Search → Evidence Builder → Pro/Con Agents → Judge Agent → Final Verdict

(See `architecture.png` for visual diagram)

---

## ✨ Features

* Multi-agent debate system
* Real-time web-based evidence retrieval
* LLM-powered argument generation
* Judge-based evaluation system
* Streamlit interactive UI

---

## 🛠 Tech Stack

* Python
* Streamlit
* Groq LLM (Llama 3.1)
* DuckDuckGo Search (DDGS)
* Prompt-engineered AI agents
